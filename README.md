# IT326-DataMining-Project: 
# Predictive Modeling for Credit Risk Assessment

### Project Description

This project focuses on analyzing and classifying credit risk using the German Credit dataset. The dataset contains information about individuals who applied for credit, including demographic, financial, and credit-related characteristics.

The main objective is to develop a classification model that predicts whether an individual’s credit risk is Good or Bad based on the selected attributes. The project aims to identify patterns in the data that can help distinguish between low- and high-risk applicants.


### Project Motivation

Credit risk assessment is important for banks because lending money involves the risk that borrowers may not repay their credit. An inaccurate decision can lead to financial losses or missed lending opportunities.

We chose the German Credit dataset because it represents a practical real-world classification problem and contains both personal and financial information about credit applicants. The clear Good/Bad risk classification also makes it suitable for applying machine learning techniques and studying the factors associated with credit risk.
